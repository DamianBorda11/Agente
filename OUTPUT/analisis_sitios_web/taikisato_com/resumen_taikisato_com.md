# Resumen — taikisato.com

**URL:** https://taikisato.com

Portfolio de Taiki Sato, diseñador visual con base en Tokio, enfocado en web design,
graphic design y dirección de arte. El home se presenta con una declaración personal
("balancing logical and intuitive thinking, function and emotion...") antes de mostrar
cualquier trabajo, posicionándolo como diseñador con una filosofía propia, no solo un
catálogo de piezas.

**Enfoque:** mezcla storytelling breve con una grilla curada de 5 proyectos (2022-2024),
cada uno etiquetado por tipo (PRIVATE WORKS / CLIENT WORKS) y disciplina (ART DIRECTION,
WEB DESIGN, GRAPHIC DESIGN). El tono es introspectivo y editorial, apoyado en textos
bilingües japonés/inglés.

**Público objetivo:** marcas, estudios o clientes japoneses que buscan dirección de arte y
diseño web-gráfico con una sensibilidad autoral, no un proveedor genérico.

**Estructura:** header fijo con logo y 3 enlaces de texto (contacto, trabajos, about) más un
botón MENU que abre un overlay a pantalla completa. El home tiene 3 secciones: hero (intro +
esfera en shader WebGL), teaser de "about" (collage de fotos + link) y grilla de trabajos
(5 proyectos + link a "ver todos"). Footer con navegación repetida, redes y "back to top".

**UX:** la navegación principal vive en el overlay fullscreen (no en el header, que solo
tiene accesos directos). La transición entre páginas usa un wash de color sólido antes de
revelar el contenido nuevo, dando sensación de pulido. La página de works suma filtros por
disciplina (ALL, ART DIRECTION, WEB DESIGN, etc.).

**UI:** paleta neutra beige/gris oscuro, tipografía serif japonesa (Zen Old Mincho),
fotografía en blanco y negro para el menú, y una esfera tipo luna renderizada con shader
como elemento decorativo del hero — combina minimalismo editorial con un toque técnico.
